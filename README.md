# Nova Vanguard

*100 levels. 20 heroes. One endless challenge.*

A side-scrolling space shooter built with React, HTML5 Canvas and plain JavaScript, with Supabase accounts, cloud saves and server-verified ranked leaderboards, deployed on Vercel.

> Renamed from **Lumi Blaster**. Database tables, storage keys and account IDs are unchanged, so existing players keep their progress.

---

## 1. What you need

| Service | Why | Cost |
|---|---|---|
| **Supabase** project | Sign-in codes, database, row-level security | Free tier is enough to start |
| **Vercel** project | Hosts the game and the two ranked-run API functions | Free (Hobby) |
| **SMTP email provider** (Resend, SendGrid, Postmark…) | Supabase's built-in sender only allows a few emails per hour | Usually free at low volume |
| **SMS provider** in Supabase (Twilio, MessageBird, Vonage, Textlocal) | *Optional:* sign-in by mobile number | Paid per message |

Without an SMS provider, players simply use email. The game shows a clear message if someone tries a phone number.

## 2. Set up Supabase (about 10 minutes)

1. Create a project at **supabase.com**.
2. **SQL Editor** → run every file in `supabase/migrations/`, oldest first (three files).
3. **Authentication → Providers (Sign In / Providers) → Email:** enabled.
   - **Confirm email ON** (recommended): new players verify with a 6-digit code (or by tapping the link) before playing.
   - **Confirm email OFF**: players sign up with username + password and play immediately. Quickest for testing.
4. **Custom SMTP (needed to edit emails):** Supabase locks the email templates until you add your own sender. Under **Authentication → Emails → SMTP Settings**, enable custom SMTP. A Gmail account works for small games: host `smtp.gmail.com`, port `587`, your Gmail address as username, and a Google **App password** (Google Account → Security → App passwords; needs 2-Step Verification).
5. **Authentication → Emails → Templates:** put the code in these templates so the email matches the game’s “enter your code” screen:
   - **Confirm signup**, **Magic Link** (used for one-time-code sign-in and password reset):
   ```html
   <h2>Your Nova Vanguard code</h2>
   <p style="font-size:28px;letter-spacing:6px"><b>{{ .Token }}</b></p>
   <p>Or <a href="{{ .ConfirmationURL }}">tap here</a> instead.</p>
   ```
   Until you do this, emails contain only a link. That still works: the game tells players to tap it, and the open game screen continues automatically.
6. *(Optional)* **Authentication → Providers → Phone:** enable it and connect an SMS provider (Twilio, MessageBird, Vonage or Textlocal). Without one, players use email; the game explains this if someone tries a phone number.
7. **Authentication → URL Configuration:** set **Site URL** to your Vercel address and add it under **Redirect URLs**.
8. **Authentication → Rate Limits:** username sign-ins are processed by the game’s server, so they all reach Supabase from Vercel. If many players sign in at once, raise the sign-in limit here.
9. **Project Settings → API Keys → Legacy API keys:** copy the **anon public** and **service_role** keys (both start with `eyJ`). **Project Settings → Data API:** copy the **Project URL** (`https://xxxx.supabase.co`).

## 3. Deploy on Vercel

1. Push this folder to GitHub, with `package.json` at the top level of the repo.
2. In Vercel: **Add New → Project → Import** the repo. The included `vercel.json` sets the build (`node tools/build.js`) and output folder (`public`), so leave those fields alone.
3. **Settings → Environment Variables**, for Production, Preview and Development:

   | Name | Value |
   |---|---|
   | `SUPABASE_URL` | Project URL |
   | `SUPABASE_ANON_KEY` | anon public key |
   | `SUPABASE_SERVICE_ROLE_KEY` | service_role key (**server only, never shown to players**) |

4. **Deploy**. If a variable is missing, the game shows a "Server setup needed" screen naming it.
5. Before launch, edit `tools/static/support.html` (support email) and review `privacy.html` and `terms.html`.

## 4. Run locally

The game needs its API functions, so use the Vercel CLI rather than a plain file server:
```bash
npm install
npm install -g vercel
vercel link          # connect to your Vercel project (once)
vercel env pull      # downloads the environment variables into .env.local
npm run build
vercel dev           # http://localhost:3000
```
Add `http://localhost:3000` to Supabase **Redirect URLs** if you want email links to work locally.

## 6. How ranked endless stays fair

Ranked rules are at **version 5** (three lives, contact-only enemies, armored and fast enemy families, continuous spawns plus a bigger staggered wave every 20 seconds).

- `run-start` creates a server-side run session with a random seed.
- The seed fully determines the enemy schedule, elite placement and drops, so every player faces the same rules.
- The browser records only events (kills, pickups, hits, blasts). `run-submit` rebuilds the schedule, checks every event against timing and firepower limits, and **computes the score itself**.
- Duplicate, cross-account, expired and impossible runs are rejected with a reason. Leaderboard rows can only be written by the server.

## 8. Nickname play (no account needed)

Players tap **Play Now**, type a nickname, and start playing. Behind the scenes the game uses Supabase **anonymous sign-ins**: each device gets a private guest account linked to the nickname, so cloud saves, ranked Endless and leaderboards all work without an email or password.

**Two settings in Supabase:**
1. **Authentication → Sign In / Providers → Allow anonymous sign-ins: ON.**
2. **SQL Editor:** run `supabase/migrations/20261027000000_nickname_play.sql` (lets guests claim nicknames).

Nicknames follow the username rules (3–20 letters, numbers, underscores) and are unique. A guest can open **Profile → Keep your progress safe** to add an email and password; after that they can sign in with their nickname on any device, and nothing is lost. Signing out of a guest profile shows a warning first, because guest progress is tied to that device.

If anonymous sign-ins are off or the server can’t be reached, the game still lets people play with a nickname and a **local save on the device**; Endless runs are then unranked practice. Players who already have a username and password use **Sign in** on the start screen.

## 8b. Accounts (optional)

- **Sign up:** username → password (8+ characters with a letter and a number) → email or mobile number → verify (if enabled) → play.
- **Sign in:** username + password. The server (`api/login.js`) looks up the account privately, so emails and phone numbers are never revealed.
- **Forgot password:** a one-time code to the account’s email or phone, then choose a new password. **Profile → Password** changes it while signed in.
- **Older accounts** created with one-time codes only: choose **Sign in with a one-time code**, then set a password in **Profile**.
- **Phone numbers:** pick the country code and type the rest (spaces, dashes and a leading 0 are fine). The form shows the expected format and the exact number it will text.

## 10. Phones, tablets and rotation

- **Landscape:** starting a level or an Endless run asks the browser for fullscreen landscape. This works on Android/Chrome and when the game is installed to the home screen. On iPhone/iPad Safari (which can’t lock orientation), a **Rotate your device to landscape** screen appears in portrait and pauses play; rotating back resumes the same level.
- **Sharp graphics:** the canvas renders at the device’s pixel density (up to 2×, capped at ~2.8 megapixels for large tablets), and backgrounds are pre-rendered at the same resolution, so art stays smooth on high-density screens. The 16:9 playfield is letter-boxed, never stretched.
- **Touch:** a floating joystick on the left (drag anywhere), auto-fire, and a Blast button on the right; moving and blasting work at the same time. Controls sit inside the safe area (notches, rounded corners, home indicator). Scrolling, pinch/double-tap zoom and text selection are blocked during play.
- **Performance:** if frames run slow, the game automatically trims effects and then canvas resolution. **Settings → Graphics** can also be set to Low manually.

## 10b. Major update: ultimates, Endless bosses, coins & shop, customization, multiplayer

- **Ultimates:** every hero has a uniquely named ultimate (the Blast button / E). Ten types: Nova ring, Cannonball, Sweeping laser, Tsunami wave, Black hole, Chain lightning, Piercing lances, Meteor shower, Homing crystal storm and Solar flare. Each has its own sound and deals the original blast's damage (10, bosses 14) to what it touches, clearing enemy bullets in its area. Charges work as before (start 1, hold 3, pickups add 1).
- **Endless bosses:** every 30,000 points the field clears and an Endless-only boss arrives: Octo Queen (jellyfish bombs), Blade Sovereign (boomerang blades), Hive Matriarch (homing bees, honey bombs), Magma Titan (meteors, lava bombs), Mirror Wraith (teleports, mirror lasers) and Frost Hydra (ice beams, frost bombs). Bombs show their landing circle before they burst. Regular enemies pause until the boss falls; defeating it gives a 3,000+ bonus. Boss fights play their own driving music.
- **Fast-enemy warnings:** darts, torpedoes, drills and wasps flash a red marker at the right edge about 1.2 s before they enter, in both modes.
- **Joystick sensitivity:** Settings → Joystick sensitivity (Low / Normal / High / Max).
- **Coins & shop:** every Campaign level, Endless run and multiplayer match converts points to coins (1 per 100 points; +5 for a duel win). Spend them in **Shop** on locked heroes, 14 skins and customization parts. Everything is cosmetic: stats and hitbox never change.
- **Customization (Avatars → Customize):** headwear, wings, ride (glider, hoverboard, skateboard, none), weapon (cannon, bow, sniper, gun, wand, shield; changes projectiles), outfit color and boots. Defaults are free; extras cost coins.
- **Multiplayer (survival duel):** create a room and share the 6-letter code or invite link; your friend picks a nickname and joins automatically. Both players get the same waves; each plays on their own screen with a live view of the rival. Whoever survives longest wins. Uses **Supabase Realtime** (broadcast + presence), which is on by default in Supabase projects; no database changes needed. Duels are unranked.

## 11. Gameplay reference (rules version 11)

- **Endless bosses (ranked):** due at each 30,000 points; the server rebuilds the score timeline to check each boss started on time, was beaten at a possible rate, and that paused spawns resumed correctly. Rocks and shot-down projectiles score nothing in Endless.

- **Scoring (both modes):** points are awarded once, when an enemy is defeated: basic 5, tougher 10, larger 15, and +5 for each higher tier (armored Bulwarks 15–30, elites +2 tiers). There are no point pickups. Survival milestones, level-clear, health, no-hit, boss and max-power bonuses are unchanged.
- **Lives:** every run starts with 3 lives and nothing restores them.
- **Damage (both modes, active play time):** each bullet deals ×1 damage, then ×2 at 5:00, ×3 at 10:00, ×4 at 15:00 and ×5 at 20:00 (no further growth), announced with a “Damage ×N!” banner. Bullet power-ups (Comet, Nova, Prism) multiply damage while active, on top of the stage bonus: ×2, then ×3 at 5:00, ×4 at 10:00, ×5 at 15:00 and ×6 from 20:00. In Campaign, harder worlds raise the power-up multiplier too (worlds 4–6 ×3, 7–9 ×4, 10 ×5). The HUD shows the current multiplier.
- **Blast charges (both modes):** the special blast uses stored charges. You start every run and every Campaign level with 1, can hold up to 3, and each Blast pickup adds one. Blast pickups arrive every 30 seconds (first at 0:30), then faster as the crowds grow: every 10 s from 5:00, 8 s from 10:00, 6 s from 15:00 and 5 s from 20:00. Each blast uses one; there is no automatic recharge. The HUD and the mobile Blast button show your charges.
- **Shields:** a shield pickup about every 60 seconds (first at 0:30). Occasional bullet power-ups still drop, and every elite drops a weapon upgrade (1 → 3 → 6 shots).
- **Durability (both modes, active play time only):** basic enemies need 1 hit in the first minute, 2 in the second, up to 5 from minute four. Tougher tiers scale from their base (a 5-hit enemy needs 10 after one minute). **Hit caps:** basic 5, fast 10, big/armored/elite 15. Only newly spawned enemies are affected. Campaign resets this timer every level; later Campaign worlds add +25% to non-basic enemies every 20 levels.
- **Campaign:** more enemies and groups per level, with fast Darts (warned before rushing) from world 1 level 4, armored Bulwarks whose tier rises with the world, and two extra mixed waves. The weapon resets to one shot at the start of every level.
- **Endless:** continuous spawns plus a larger, staggered wave every 20 seconds (“Wave incoming!” warning, two lanes always open, Darts at least 0.6 s apart). Every five minutes enemy numbers double (2× at 5:00, 4× at 10:00, 8× at 15:00, 16× at 20:00, then no further growth), enemy speed rises 25% (also stopping at 20:00), and non-basic durability rises 50% within the hit caps. At most **50 enemies** are on screen at once, the same on every device. Enemies never shoot. The HUD shows wave, score, survival time and your records. Everything resets each run.
